# Claude Code 初学者教程设计文档

> 面向完全编程新手的分章节学习小册子，从零开始学会与 Claude Code 协作完成编程任务。

---

## 1. 目标读者

- **完全没有编程基础**，或仅有极少代码接触经验的纯新手
- 想找到一种低门槛、高成就感的方式进入编程世界
- 希望通过与 AI 对话的方式学习，而非先看大量理论知识

## 2. 教程定位

- **形式**：分章节的电子小册子/学习文档，共 6 章
- **风格**：Step-by-Step，每一步都配有具体的 Prompt 示例和预期结果
- **原则**：所有练习项目均为单文件或极简结构，避免复杂的工具链配置（npm、构建工具等），确保读者始终聚焦在"如何与 Claude Code 协作"这一核心目标上

## 3. 项目组合

| 序号 | 名称 | 类型 | 技术栈 | 核心教学点 |
|---|---|---|---|---|
| 1 | 心情记录卡片 | 前端小网页 | HTML + CSS + Vue 3 (CDN) | 需求描述 → 代码生成 → 运行验证 |
| 2 | 天气查询脚本 | Python 实用脚本 | Python 3 + 和风天气 API | API 调用、文件读写、报错排查 |
| 3 | 记账小应用 | 综合实战 | HTML + CSS + Vue 3 (CDN) | 需求拆分、功能整合、数据持久化 |

## 4. 章节结构

### 第 0 章：准备工作

**目标**：把 Claude Code 跑通，建立最小可用的开发环境。

1. 安装 Claude Code（macOS / Windows / Linux）
2. 注册与登录 Anthropic 账号
3. **连接国内模型**：配置自定义 Base URL 与模型参数（如 DeepSeek / 通义千问 / 其他兼容 API），通过 `CLAUDE.md` 或环境变量实现
4. **为什么要有 CLAUDE.md**
   - 通俗解释：它是给 Claude Code 的"系统提示词"和"项目记忆"
   - 什么时候需要写：项目规范、常用命令、个人偏好、模型配置
   - 基础写法示例：YAML Frontmatter + Markdown 内容
   - 实战：写一条"请用中文回复，代码注释用中文"的规则
5. 验证配置是否生效
6. 认识终端/命令行：切换目录、运行文件、查看报错

### 第 1 章：第一次对话 — 心情记录卡片

**目标**：完成第一次"描述需求 → AI 写代码 → 自己运行 → 看到效果"的完整循环。

**项目效果**：
- 单个 HTML 文件，通过 CDN 引入 Vue 3
- 用户可选择心情表情（开心/平静/难过/兴奋）
- 输入一句话描述，点击"生成卡片"
- 页面下方按时间顺序出现心情卡片

**教学重点**：
- 如何开口向 Claude Code 描述需求
- 如何把 AI 生成的代码保存到文件并运行
- 如何在浏览器中查看效果

**本章挑战**：让卡片背景色根据心情自动变化（开心=暖黄，平静=浅蓝，难过=灰蓝，兴奋=粉红）。

### 第 2 章：代码解释与修改

**目标**：学会请 AI 解释代码，并精确表达修改需求。

**教学场景**（基于第 1 章项目迭代）：

1. **代码解释**
   - Prompt："请逐段解释这个 HTML 文件里的代码是什么意思"
   - 学习 `<template>` / `<script>` / `<style>` 的分工

2. **修改样式**
   - Prompt："我想让卡片在鼠标放上去的时候微微向上浮起，并加深阴影，请帮我改 CSS"
   - 对比模糊需求 vs 精确需求的效果差异

3. **添加功能**
   - Prompt："给每张卡片右上角加一个删除按钮，点击后确认再删除"
   - 体验功能迭代流程

**教学重点**：
- 精确的 Prompt 效果更好
- 小步迭代，每次只改一个地方
- 遇到报错时如何反馈给 AI

**本章挑战**：加一个"清空所有记录"按钮，并带二次确认提示。

### 第 3 章：走出浏览器 — 天气查询脚本

**目标**：第一次写脚本程序，理解 API 和文件读写。

**项目效果**：
- 终端运行 `python weather.py`
- 询问用户城市名
- 调用和风天气 API 获取实时天气
- 在终端打印结果
- 保存为 `城市名-YYYY-MM-DD.txt` 文件

**教学重点**：
- 脚本与网页的区别（无浏览器界面，直接运行）
- API 通俗解释（餐厅菜单与后厨的比喻）
- 网络报错、城市名错误的排查
- 文件读写基础
- API Key 的申请与使用（和风天气需要注册）

**与 Claude Code 的互动步骤**：
1. 描述需求，生成初版代码
2. 运行，遇到报错把信息贴回
3. 添加"用户输入城市名"交互
4. 添加"结果保存为文件"功能

**本章挑战**：让脚本支持查询未来 3 天天气预报，并写入同一个文件。

### 第 4 章：综合实战 — 记账小应用

**目标**：学会拆解需求，分步骤实现一个完整的功能性应用。

**项目效果**：
- 顶部统计：本月总收入、总支出、结余
- 中部表单：类型（收入/支出）、分类下拉框、金额、备注、日期
- 底部列表：所有记录，支持删除
- 数据刷新不丢失（使用 `localStorage`）

**分步实现路径**：
1. 搭建页面骨架（静态表单 + 空白列表）
2. 添加数据绑定（点击"添加"后列表实时更新）
3. 加入分类和收支类型（收入绿、支出红）
4. 实现统计区域（自动计算总收入/支出/结余）
5. 添加删除功能 + localStorage 持久化

**教学重点**：
- 如何把"做一个记账应用"拆成 5 个小任务
- 用 Claude Code 做代码审校和结构优化
- Bug 定位：描述问题的技巧（"加了删除后统计没更新"）

**本章挑战**：添加按月筛选功能，只显示选中月份的记录和统计。

### 第 5 章：进阶与日常技巧

**目标**：建立日常使用的工具箱，能处理更复杂的场景。

**内容结构**：

1. **调试三板斧**
   - 直接粘贴报错信息
   - 让 AI 解释日志/输出
   - Working Backwards：从预期结果反推问题

2. **重构与优化**
   - 代码太长时如何拆分
   - 让 AI 帮忙起更好的变量名
   - "这段代码能更简洁吗？"

3. **更高效的 Prompt 技巧**
   - 给 AI 提供上下文（"这是 Vue 3 的单文件 HTML"）
   - 要求 AI 先给思路再写代码
   - 用 "请解释你为什么要这样改" 来学习

4. **多文件项目管理**
   - 什么时候该拆分文件
   - 让 Claude Code 帮你整理目录结构
   - 批量修改多个文件

5. **Skills 速查表**
   - 什么是内置 Skills（如 `/commit`、`/review-pr`）
   - 什么时候可以用 Skills 提升效率
   - 如何查看当前可用的 Skills 列表

6. **下一步学习建议**
   - 想学前端：推荐路径（HTML/CSS → JavaScript → Vue/React → 全栈）
   - 想学 Python：推荐路径（基础语法 → 爬虫/自动化 → 数据分析/后端）
   - 持续在 Claude Code 中练手的建议

## 5. 附录：常见踩坑指南

一个独立的 troubleshooting 章节，收集初学者在真实学习中反复遇到的问题。

### 安装与环境类
- **Claude Code 安装失败**：Node.js 版本过低、网络被拦截、权限不足
- **终端打不开/找不到命令**：Path 环境变量问题、Shell 类型差异（Bash vs Zsh vs PowerShell）
- **"python" 命令不存在**：Windows 需用 `py`，macOS/Linux 需用 `python3`

### 网络与模型类
- **连接国内模型后没有响应**：Base URL 填错、API Key 过期、模型名称拼写错误
- **Claude Code 登录超时**：代理设置、防火墙拦截

### 运行与报错类
- **HTML 文件打开是白板**：Vue CDN 加载失败（网络问题）、代码语法错误
- **Python 脚本提示 `ModuleNotFoundError`**：第三方库未安装、使用了 Python 2
- **和风天气 API 返回错误码**：城市名编码问题、API Key 未生效、免费额度超限
- **localStorage 数据消失**：开启了隐私模式、手动清除了浏览器数据、使用了不同域名打开文件

### 与 AI 协作类
- **Claude Code 给的代码跑不通**：怎么把报错信息贴回去、怎么要求它重新检查
- **AI 改错地方/没理解需求**：如何用更精确的 Prompt 重新描述
- ** Claude Code 把代码改乱了**：怎么用 Git 回退（基础版，不做深入讲解）

## 6. 技术约束与说明

- **Vue 3 通过 CDN 引入**：避免 Node.js / npm / Vite 等构建工具，降低新手门槛
- **Python 优先使用标准库**：尽可能减少 `pip install` 的频次
- **所有项目均为本地运行**：不涉及服务器部署、域名、数据库等概念
- **Prompt 示例全程陪伴**：每一章都给出可直接复制使用的对话示例
