# 有虞陶唐 · 推位让国

> 一句白话：尧（陶唐氏）不把帝位传给儿子，而让给舜（有虞氏），舜又让给禹——中国历史上最著名的权力和平交接，叫"禅让"。

## 它解决什么问题

最高权力怎么交接才不流血？儒家拿禅让当理想答案：选贤任能，而不是父死子继。

## 我的解释 / 例子

- **陶唐** = 尧，国号陶唐；**有虞** = 舜，国号有虞。千字文句序是"有虞陶唐"，记住倒装即可。
- 尧考察舜多年（把两个女儿嫁给他、让他历经各种职务和考验），确认贤能后才"推位让国"。
- 这套叙事主要见于《尚书·尧典》和《史记·五帝本纪》，是儒家政治理想的原型；后世也有人对禅让的真实性存疑（如曹丕受禅后说"舜禹之事，吾知之矣"）。
- 记忆钩子：唐尧 → 虞舜，顺序别背反；"推位让国"四个字就是"把位置和国都推出去"。
