## 白话串讲

- **都邑华夏，东西二京**：华夏的都城，有东西两座——东京洛阳、西京长安。→ [两京卡](./c4-两京与宫殿.md)
- **背邙面洛，浮渭据泾**：洛阳背靠邙山、面临洛水；长安临着渭水、依着泾水。（浮 = 临，据 = 依）
- **宫殿盘郁，楼观飞惊**：宫殿回环深曲，楼台高得令人惊叹。
- **图写禽兽，画彩仙灵**：墙壁上画着飞禽走兽，彩绘着神仙精灵。
- **丙舍旁启，甲帐对楹**：配殿从旁开启，宝帐对着殿柱（丙舍 = 宫中正殿旁的别室；甲帐 = 汉武帝以珠宝编次的宝帐）。
- **肆筵设席，鼓瑟吹笙**：摆开筵席，鼓瑟吹笙（《诗经·小雅》"肆筵设席"）。
- **升阶纳陛，弁转疑星**：登上殿阶，群臣的礼帽转动起来好像满天繁星（弁 = 官帽）。
- **右通广内，左达承明**：向右通往广内殿（宫廷藏书处），向左直达承明殿（侍臣值宿、研讨学问处）。
- **既集坟典，亦聚群英**：这里既汇集《三坟》《五典》等古书，也聚集众多英才。
- **杜稿钟隶，漆书壁经**：藏有杜度的草书、钟繇的隶书，还有漆书竹简与孔壁古文经。→ [壁经卡](./c4-坟典漆书壁经.md)
- **府罗将相，路侠槐卿**：府中罗列将相人才，路上站满公卿（周代三公面三槐而立，"侠"同"夹"）。
- **户封八县，家给千兵**：功臣之家封赏八县，配给上千兵士。
- **高冠陪辇，驱毂振缨**：高官陪侍皇帝车辇，驱车疾行、帽缨飞扬。
- **世禄侈富，车驾肥轻**：世代俸禄、奢侈富足，乘肥马、衣轻裘。
- **策功茂实，勒碑刻铭**：把丰功伟绩刻在碑上，永世铭记。

## 场景叙事（四段：城 → 宫 → 书 → 仪）

1. **两京形胜**（1–2）：邙山洛水 / 渭水泾水
2. **宫殿巡游**（3–7）：盘郁宫殿 → 彩画 → 甲帐 → 鼓瑟笙歌 → 星点官帽
3. **藏书的荣耀**（8–10）：广内承明 → 坟典群英 → 杜稿钟隶漆书壁经
4. **帝国排场**（11–15）：将相公卿 → 封县千兵 → 陪辇振缨 → 肥马轻裘 → 勒碑刻铭
