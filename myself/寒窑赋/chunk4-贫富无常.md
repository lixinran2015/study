# 寒窑赋 chunk4 · 转（第 4 段）

> 六组"错位"（贫富、才遇、贵贱、美丑、龙鳖、君小人）之后，笔锋一转：衣服破没关系，守住仪礼；时运不济没关系，守住心——"初贫君子"与"乍富小人"的一锤定音。

## 原文

有先贫而后富，有老壮而少衰。

满腹文章，白发竟然不中；才疏学浅，少年及第登科。

深院宫娥，运退反为妓妾；风流妓女，时来配作夫人。

青春美女，却招愚蠢之夫；俊秀郎君，反配粗丑之妇。

蛟龙未遇，潜水于鱼鳖之间；君子失时，拱手于小人之下。

衣服虽破，常存仪礼之容；面带忧愁，每抱怀安之量。

时遭不遇，只宜安贫守份；心若不欺，必然扬眉吐气。

初贫君子，天然骨格生成；乍富小人，不脱贫寒肌体。

## 逐句白话

- **有先贫而后富，有老壮而少衰**：有人先贫后富，有人少壮却早衰——命运本无常态。
- **满腹文章，白发竟然不中**：满腹学问的人，头发白了竟然考不中。
- **才疏学浅，少年及第登科**：才学浅薄的人，少年就及第登科。
- **深院宫娥，运退反为妓妾**：深宫里的宫女，运道一退反而沦为妓妾。
- **风流妓女，时来配作夫人**：风尘女子，时来运转配作夫人。
- **青春美女，却招愚蠢之夫**：青春美女，却招了个愚蠢的丈夫。
- **俊秀郎君，反配粗丑之妇**：俊秀男儿，反而配上粗丑的妻子。
- **蛟龙未遇，潜水于鱼鳖之间**：蛟龙没有机遇，潜身在鱼鳖之间。
- **君子失时，拱手于小人之下**：君子失了时运，拱手屈居小人之下。
- **衣服虽破，常存仪礼之容**：衣服虽破，常存礼仪的仪容。
- **面带忧愁，每抱怀安之量**：面带忧愁，常怀安定的气量。
- **时遭不遇，只宜安贫守份**：时运不济，只应安守本分。
- **心若不欺，必然扬眉吐气**：内心不自欺（不自弃），必然有扬眉吐气的一天。
- **初贫君子，天然骨格生成**：起初贫穷的君子，天生骨格（品格）已成。
- **乍富小人，不脱贫寒肌体**：暴富的小人，脱不掉贫寒的肌体。

## 对照组骨架（本篇的记忆挂钩）

六组"错位" + 两组"守住" + 一锤定音：

| 错位 | 对照 |
|---|---|
| 贫富 | 白发不中 ↔ 少年登科 |
| 贵贱 | 宫娥为妾 ↔ 妓女作夫人 |
| 美丑 | 美女配蠢夫 ↔ 俊郎配丑妇 |
| 物种 | 蛟龙潜水 ↔ 鱼鳖之间 |
| 人格 | 君子失时 ↔ 小人之下 |

守住：**仪礼之容**（外）+ **怀安之量**（内）→ 结论：**骨格 vs 肌体**——贫能守出骨格，富遮不住肌体。
