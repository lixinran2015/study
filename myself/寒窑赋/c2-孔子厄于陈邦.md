# 孔子厄于陈邦

> 一句白话：文章盖世的孔子，在陈国、蔡国之间被围住，断粮七天——圣贤也有"时"不济的时候，他怎么办？继续弹琴。

## 它解决什么问题

才德与境遇不成正比的第一个例子。寒窑赋用它开篇立论：连孔子都要等"时"，何况普通人？

## 我的解释 / 例子

- 前 489 年，孔子周游列国返卫途中，在陈、蔡之间被两国大夫发兵围困于野，断粮七日，弟子病倒。
- 《论语·卫灵公》："君子固穷，小人穷斯滥矣。"——孔子在绝粮中给弟子的回答。
- "厄"è = 困厄；陈邦 = 陈国。
- 记忆钩子：**弦歌 = 绝粮七天的背景音乐**。
