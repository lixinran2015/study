# 吕蒙正与寒窑

> 一句白话：写"富贵谁不欲"的人，是北宋宰相吕蒙正——他幼年被赶出家门、和母亲住在洛阳破窑里，后来考中状元、三起三落当宰相。《寒窑赋》是他用自己的一生给"时运"二字作的注脚。

## 它解决什么问题

这篇文章为什么有说服力？因为作者不是旁观者——破窑里走出来的人谈富贵贫贱，字字有出处。

## 我的解释 / 例子

- 吕蒙正（946–1011）：北宋太宗、真宗朝宰相。幼年父母失和，与母刘氏被父亲吕龟图逐出家门，寓居洛阳破窑，靠乞讨和寺僧施舍长大。
- 太平兴国二年（977）考中状元，后官至宰相——**三次被罢、三次复相**，起落之频繁为宋臣罕见。
- 相传他作《寒窑赋》（又名《破窑赋》）自述："听由天地循环，周而复始焉。"
- 记忆钩子：**破窑 → 状元 → 宰相府 → 破窑的哲学**——一生就是一个圆。
