# 坚持雅操 · 好爵自縻

> 一句白话：守住本真与操守，高官厚禄会自己系到你身上——不是去追逐回报，而是让回报成为副产品。

## 它解决什么问题

逐物者意移：越追逐外物，心神越散。这两句给出另一条路径：以"守"为因，以"得"为果——而且"縻"（系住）说明它自己会来，不用抢。

## 我的解释 / 例子

- **守真志满，逐物意移**：守住本真，志向自然充盈；追逐外物，心意就被牵走——先立对比。
- **雅操** = 高雅的操守；**好爵** = 美官厚禄；**自縻** = 自己系来（縻 mí，系住）。
- 语出《周易·中孚》："鸣鹤在阴，其子和之；我有好爵，吾与尔靡之。"——"靡"与"縻"相通，意为共享、相系。
- 记忆钩子：**前四字"守"，后四字"得"**；中间的对照句（守真 vs 逐物）是逻辑桥。
- 与 chunk2"克念作圣"一脉相承：修身主线从个人（克念）走到关系（人伦）再回到个人（守真），形成闭环。
