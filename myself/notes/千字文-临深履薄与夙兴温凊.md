# 临深履薄 · 夙兴温凊

> 一句白话：侍奉父母要如临深渊、如履薄冰一样小心；早起问安、冬天给父母暖床、夏天给床铺扇凉——孝不是口号，是一套具体动作。

## 它解决什么问题

"要孝顺"人人都懂，难的是落到日常。"孝"如何从抽象价值变成可执行的行为规范？这两句给出的是儒家版的操作手册。

## 我的解释 / 例子

- **临深履薄**：出《诗经·小雅·小旻》"战战兢兢，如临深渊，如履薄冰"——形容侍奉父母时敬畏谨慎的心态。再往上溯，"身体发肤受之父母"出《孝经》。
- **夙兴温凊**：出《礼记·曲礼》"凡为人子之礼，冬温而夏凊"——夙兴 = 早起（问安），温凊 = 冬天让父母温暖、夏天让父母清凉。"凊"读 qìng，是"使……凉"的意思，字形与"清"极近易混。
- 记忆钩子：**前四字是"怕"（敬畏之心），后四字是"勤"（日常功课）**——孝 = 敬畏 + 勤奋。
- 这两句也是 chunk1"身体发肤"的延续：因为身体是父母的，所以毁伤是罪，奉养是礼。
