# 易輶攸畏 · 属耳垣墙

> 一句白话：哪怕是再轻易说出口的话，也要心怀敬畏——因为墙那边，有耳朵。

## 它解决什么问题

言语风险：祸从口出。越是不经意的话，越可能传得越远、变得越变形。

## 我的解释 / 例子

- **易輶**：輶（yóu）本义是轻车，引申为"轻易"；"易輶攸畏" = 轻易的话也要有敬畏。
- **属耳**：附耳，贴着墙偷听；**垣墙**：墙壁。
- 两句互为因果：正因隔墙有耳，轻易之言也要慎。
- 记忆钩子：**"輶"字记法 = 车 + 酋，很轻的车 → 轻 = 轻易**；画面感极强的一句，墙与耳朵的图像自带记忆点。
