# 千字文 chunk6 · 重农与知退（第 163–188 句）

> 从治国之本（农）讲到立身之本（谦与直），最后落在"知退"——殆辱近耻时，林泉是最好的退路。

## 原文（每句后附拼音，默念时先看拼音再过字）

治本于农，务兹稼穑。 *Zhì běn yú nóng, wù zī jià sè.*
俶载南亩，我艺黍稷。 *Chù zài nán mǔ, wǒ yì shǔ jì.*
税熟贡新，劝赏黜陟。 *Shuì shú gòng xīn, quàn shǎng chù zhì.*
孟轲敦素，史鱼秉直。 *Mèng kē dūn sù, shǐ yú bǐng zhí.*
庶几中庸，劳谦谨敕。 *Shù jī zhōng yōng, láo qiān jǐn chì.*
聆音察理，鉴貌辨色。 *Líng yīn chá lǐ, jiàn mào biàn sè.*
贻厥嘉猷，勉其祗植。 *Yí jué jiā yóu, miǎn qí zhī zhí.*
省躬讥诫，宠增抗极。 *Xǐng gōng jī jiè, chǒng zēng kàng jí.*
殆辱近耻，林皋幸即。 *Dài rǔ jìn chǐ, lín gāo xìng jí.*
两疏见机，解组谁逼。 *Liǎng shū jiàn jī, jiě zǔ shuí bī.*
索居闲处，沉默寂寥。 *Suǒ jū xián chù, chén mò jì liáo.*
求古寻论，散虑逍遥。 *Qiú gǔ xún lùn, sǎn lǜ xiāo yáo.*
欣奏累遣，戚谢欢招。 *Xīn zòu lèi qiǎn, qī xiè huān zhāo.*

注：拼音按本字读音标注，不标变调。

## 白话串讲

- **治本于农，务兹稼穑**：治国的根本在于农业，致力于播种与收获（稼 = 种植，穑 = 收割）。
- **俶载南亩，我艺黍稷**：开始在南亩耕作，种植黍子和稷（《诗经》"俶载南亩"）。
- **税熟贡新，劝赏黜陟**：新粮一熟就交税进贡，并依农政劝赏、贬黜或升迁官吏。
- **孟轲敦素，史鱼秉直**：孟子崇尚质朴，史鱼（卫国大夫）秉性刚直。
- **庶几中庸，劳谦谨敕**：力求接近中庸之道，勤劳谦逊、谨慎守正（敕 = 整饬）。
- **聆音察理，鉴貌辨色**：听人说话要体察其中的道理，观察人要辨别他的神色。
- **贻厥嘉猷，勉其祗植**：把美好的谋略留给后人，勉励自己敬谨立身处世（祗 = 敬）。
- **省躬讥诫，宠增抗极**：常反省自身、听取讥诤；荣宠增加时要警惕亢极而危（抗通"亢"）。
- **殆辱近耻，林皋幸即**：危险和耻辱临近时，幸好还有山林水泽可以退居（皋 = 水岸高地）。
- **两疏见机，解组谁逼**：疏广、疏受叔侄见机辞官、解下印绶——那是谁逼他们的呢？→ [典故卡](../notes/千字文-两疏见机与解组谁逼.md)
- **索居闲处，沉默寂寥**：离群独居，沉静少言、甘于寂寞。
- **求古寻论，散虑逍遥**：探求古人言论、寻绎典籍，排散思虑、逍遥自得。
- **欣奏累遣，戚谢欢招**：让欣喜聚来、烦累遣去；让忧愁消散、欢乐招来。

## 场景叙事（四段：农 → 身 → 退 → 闲）

1. **重农**（1–3）：稼穑 → 南亩黍稷 → 税贡赏罚——农业是国家的根本
2. **立身**（4–8）：敦素/秉直（品格）→ 中庸（目标）→ 聆音鉴貌（识人）→ 省躬抗极（自警）
3. **知退**（9–10）：殆辱近耻 → 林皋幸即 → 两疏见机——见好就收的智慧 → [典故卡](../notes/千字文-林皋之隐.md)
4. **闲居**（11–13）：索居寂寥 → 求古寻论 → 欣奏累遣
