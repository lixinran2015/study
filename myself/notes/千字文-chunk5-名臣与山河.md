# 千字文 chunk5 · 名臣与山河（第 133–162 句）

> 一部"贤臣名将 + 地理名胜"速览：从姜太公、伊尹到四大名将，从泰山封禅到洞庭昆池——史与地在这里合流。

## 原文（每句后附拼音，默念时先看拼音再过字）

磻溪伊尹，佐时阿衡。 *Pán xī yī yǐn, zuǒ shí ē héng.*
奄宅曲阜，微旦孰营。 *Yǎn zhái qū fù, wēi dàn shú yíng.*
桓公匡合，济弱扶倾。 *Huán gōng kuāng hé, jì ruò fú qīng.*
绮回汉惠，说感武丁。 *Qǐ huí hàn huì, yuè gǎn wǔ dīng.*
俊乂密勿，多士实宁。 *Jùn yì mì wù, duō shì shí níng.*
晋楚更霸，赵魏困横。 *Jìn chǔ gèng bà, zhào wèi kùn héng.*
假途灭虢，践土会盟。 *Jiǎ tú miè guó, jiàn tǔ huì méng.*
何遵约法，韩弊烦刑。 *Hé zūn yuē fǎ, hán bì fán xíng.*
起翦颇牧，用军最精。 *Qǐ jiǎn pō mù, yòng jūn zuì jīng.*
宣威沙漠，驰誉丹青。 *Xuān wēi shā mò, chí yù dān qīng.*
九州禹迹，百郡秦并。 *Jiǔ zhōu yǔ jì, bǎi jùn qín bìng.*
岳宗泰岱，禅主云亭。 *Yuè zōng tài dài, shàn zhǔ yún tíng.*
雁门紫塞，鸡田赤城。 *Yàn mén zǐ sài, jī tián chì chéng.*
昆池碣石，钜野洞庭。 *Kūn chí jié shí, jù yě dòng tíng.*
旷远绵邈，岩岫杳冥。 *Kuàng yuǎn mián miǎo, yán xiù yǎo míng.*

注：拼音按本字读音标注，不标变调。

## 白话串讲

- **磻溪伊尹，佐时阿衡**：姜太公垂钓磻溪遇周文王，伊尹辅佐商汤——都是辅佐当世的贤臣（阿衡 = 伊尹之号）。→ [典故卡](../notes/千字文-磻溪伊尹与佐时阿衡.md)
- **奄宅曲阜，微旦孰营**：（周公分封）奄有曲阜之地，没有周公旦，谁能营建鲁国？（微 = 没有）
- **桓公匡合，济弱扶倾**：齐桓公匡正天下、会合诸侯，救济弱小、扶持倾危之国。
- **绮回汉惠，说感武丁**：绮里季（商山四皓之一）挽回汉惠帝的储位；傅说感动武丁，被举为相。
- **俊乂密勿，多士实宁**：贤才勤勉用事，人才众多，国家才能安宁。
- **晋楚更霸，赵魏困横**：晋文公、楚庄王相继称霸；赵、魏受困于（张仪的）连横之策。
- **假途灭虢，践土会盟**：晋献公向虞国借道灭虢，回师顺手灭虞；晋文公在践土大会诸侯，称霸天下。→ [典故卡](../notes/千字文-假途灭虢与践土会盟.md)
- **何遵约法，韩弊烦刑**：萧何订立简约的法令（约法三章→九章律）；韩非却死于自己鼓吹的繁苛刑法。
- **起翦颇牧，用军最精**：白起、王翦、廉颇、李牧，用兵最为精妙。→ [典故卡](../notes/千字文-起翦颇牧.md)
- **宣威沙漠，驰誉丹青**：威名远播沙漠，功业载入史册（丹青 = 史册）。
- **九州禹迹，百郡秦并**：九州遍布大禹治水的足迹，天下百郡被秦国兼并。
- **岳宗泰岱，禅主云亭**：五岳之宗是泰山（岱宗），封禅的坛场在云云山、亭亭山。
- **雁门紫塞，鸡田赤城**：雁门关、长城（紫塞），鸡田驿站、赤城山——边塞名地。
- **昆池碣石，钜野洞庭**：昆明池、碣石山、钜野泽、洞庭湖——四方名胜。
- **旷远绵邈，岩岫杳冥**：山川辽阔连绵，峰峦幽深杳渺。

## 场景叙事（七段）

1. **开国辅臣**（1–2）：磻溪钓翁姜尚 → 佐汤伊尹 → 营鲁周公
2. **霸业与储君**（3–4）：齐桓公尊王攘夷 → 四皓保储 → 傅说拜相
3. **贤才治国**（5）：人才 = 国力
4. **春秋晋事**（6–8）：晋楚争霸 → 假途灭虢（贪小利亡国）→ 践土会盟（会盟称霸）→ 萧何约法 / 韩非死于刑
5. **战将与武功**（9–10）：起翦颇牧 → 威宣沙漠
6. **大一统**（11–12）：禹画九州 → 秦并百郡 → 泰山封禅
7. **名山大川**（13–15）：雁门长城 → 昆池洞庭 → 岩岫杳冥
