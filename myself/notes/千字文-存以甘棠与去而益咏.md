# 存以甘棠 · 去而益咏

> 一句白话：召公在甘棠树下办公，百姓爱戴他，连那棵树都舍不得砍——真正的好官，人走了，口碑反而更盛。

## 它解决什么问题

为官（或做任何公共角色）该留下什么？不是政绩工程，而是"去后思"——人离开后，被怀念的程度才是德政的度量衡。

## 我的解释 / 例子

- **召公奭**（shì）：周文王之子、武王之弟，辅佐武王灭商、成王治国，与周公旦分陕而治。
- 他巡行南国时，就在一棵甘棠树下听讼断狱、处理政务，不入民宅、不扰百姓。
- 百姓作《诗经·召南·甘棠》怀念他："蔽芾甘棠，勿翦勿伐，召伯所茇。"——树因为人而珍贵，请别剪别砍。
- "存以甘棠" = 在任时留下召公那样的德政；"去而益咏" = 离任后歌颂反而更多（益 = 更加）。
- 记忆钩子：**树因人贵，去后更咏**——四个字"存"，四个字"去"，对照着背。
