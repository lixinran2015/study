# 千字文 chunk3 · 人伦与操守（第 77–102 句）

> 从"学而优则仕"讲起：先论为官之德，再铺开一张人伦关系地图（夫妇、宗族、兄弟、朋友），最后收在个人操守——守真自有回报。

## 白话串讲

- **学优登仕，摄职从政**：学问优秀就出来做官，担任职务、参与政事。（《论语》：学而优则仕。）
- **存以甘棠，去而益咏**：在任时像召公那样留下德政，离任后百姓反而更加怀念歌颂。→ [典故卡](../notes/千字文-存以甘棠与去而益咏.md)
- **乐殊贵贱，礼别尊卑**：音乐随贵贱身份而有别，礼制用来区分尊卑秩序。
- **上和下睦，夫唱妇随**：上下和睦，夫妻相倡相随。
- **外受傅训，入奉母仪**：在外接受师傅的教导，在家遵奉母亲的仪范。
- **诸姑伯叔，犹子比儿**：对姑、伯、叔等尊长要敬爱；兄弟之子（犹子）视同己出。
- **孔怀兄弟，同气连枝**：兄弟间要深怀关爱（孔怀），因为本是同气连枝。→ [人伦地图](../notes/千字文-人伦秩序.md)
- **交友投分，切磨箴规**：交朋友要情投意合，彼此切磋磨砺、劝诫规谏。
- **仁慈隐恻，造次弗离**：仁爱、慈悲、恻隐之心，再匆忙仓促也不能丢弃。
- **节义廉退，颠沛匪亏**：气节、正义、廉洁、谦逊，在困顿流离中也不亏损。匪 = 不。
- **性静情逸，心动神疲**：心性安静，情志就安逸；心为物役，精神就疲累。
- **守真志满，逐物意移**：守住本真，志向自然充盈；追逐外物，心意就被牵走。
- **坚持雅操，好爵自縻**：坚守高雅的操守，高官厚禄自然随之而来。→ [典故卡](../notes/千字文-坚持雅操与好爵自縻.md)

## 场景叙事（六段：政 → 序 → 亲 → 友 → 守 → 得）

1. **出仕之德**（1–2）：学优登仕 → 甘棠遗爱
2. **礼乐之序**（3–4）：贵贱尊卑、夫妇和睦
3. **家族之亲**（5–8）：傅训母仪、诸姑伯叔、兄弟孔怀
4. **朋友之谊**（9）：交友投分、切磨箴规
5. **操守底线**（10–11）：造次弗离、颠沛匪亏
6. **守真之得**（12–13）：性静守真 → 好爵自縻
