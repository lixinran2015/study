# myself · 极简闭环学习体系

为「学了就忘、知识散乱」而设计的学习体系。载体：纯 Markdown + git。

## 核心思想

学了就忘，根因不是记得不够努力，而是缺少**提取和输出**。知识只有被反复调用、用自己的话重组、用到真实问题中，才会真正留下来。所以本体系的重点不是"存得整齐"，而是让知识转起来：

```
捕获 → 加工 → 连接 → 提取 → 输出 ↺
```

## 目录结构

```
myself/
├── README.md          ← 本文件：体系说明 + 操作清单
├── inbox.md           ← 捕获：随手丢，不加工不分类
│
├── 千字文/            ← 主题一（自包含：地图 + 正文 + 卡片 + 打卡）
├── 三字经/            ← 主题二（待建）
├── 寒窑赋/            ← 主题三（待建）
│
├── notes/             ← 跨主题概念卡（费曼式，如"禅让制"）
│   └── _template.md
├── maps/              ← 总目录：从这里进入任何主题
│   ├── README.md
│   └── _template.md
├── output/            ← 输出：月度总结、文章、实践应用
│   └── _template.md
└── reviews/           ← 复盘：周复盘 + 月复盘
    ├── weekly/_template.md
    └── monthly/_template.md
```

每个主题目录自包含四件套：**主题地图**（总览 + 学习计划）、**chunk 正文**（原文 + 拼音 + 🎬 镜头）、**典故卡**（c1、c2… 前缀按块排序）、**背诵打卡**。

## 流转规则

| 阶段 | 时机 | 动作 | 规则 |
|---|---|---|---|
| 捕获 | 随时，<1 分钟 | 想法/书摘/灵感丢进 `inbox.md` | 不加工、不分类、零负担 |
| 加工 | 每周，约 15 分钟 | 清空 inbox：每条要么变成 `notes/` 概念卡，要么删除 | inbox 不留存货 |
| 连接 | 加工时同步 | 新卡必须链接至少一张 map 或另一张卡 | 连不上 = 还不值得留 |
| 提取 | 每周复盘，5 分钟 | 随机抽 3 张旧卡，不看原文回忆 | 记不得 → 重新加工或删除 |
| 输出 | 每月，1 小时 | 从 maps 挑主题写一篇 `output/`，或把某个模型用到真实问题 | 输出是"真学会"的唯一标准 |

## 每周 30 分钟（固定时间，写进日历）

1. 背本周块：各部经典按各自地图的学习计划推进（一次只背一块新内容）
2. 抽背旧块：不看原文，至少抽一块旧块 + 报出歌诀/对照组骨架
3. 把结果填进各部经典目录下的 背诵打卡.md，错字进错字本
4. 清空 inbox：每条要么变成笔记，要么删除
5. 写周复盘（`reviews/weekly/YYYY-MM-DD.md`，复制模板）
6. `git commit`

## 每月 1 小时（固定时间，写进日历）

1. 写一篇输出（`output/`）：经典串讲、文章，或实践应用记录
2. 更新各部经典地图：进度、卡片增删、未解问题的答案
3. 写月复盘（`reviews/monthly/YYYY-MM.md`，复制模板）
4. `git commit`

## 冷启动（第一周）

- **第 1 天**：把每周/每月的固定时间订进日历
- **第 1 周**：跳过 inbox，把"最近学过但快忘掉"的东西直接写 3~5 张概念卡，建第一张主题地图。先跑一遍闭环，体验比完善更重要。

## 验收信号（不看笔记数量）

- [ ] 每周 inbox 能清空
- [ ] 抽卡回忆成功率逐月上升
- [ ] 每月至少一篇输出

## 默认约定

- **inbox 是单个文件**，不是文件夹——摩擦最低
- **不复读旧笔记，只随机抽卡回忆**——重读是熟悉的幻觉，回忆才是提取
- 超过两周没处理的 inbox 整批丢弃——不追债，接受遗忘是体系的一部分
- 每次复盘后 commit，git 历史本身就是学习轨迹
