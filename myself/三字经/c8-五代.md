# 五代

> 一句白话：唐亡到宋兴之间的五十三年，中原换了五个朝代——后梁、后唐、后晋、后汉、后周，合称"五代"；十国在周边并立。

## 它解决什么问题

唐宋之间不是空白，而是"五代十国"的大碎裂——这段最乱的历史，用五个姓就能拎起来。

## 我的解释 / 例子

- **五代（907–960）**：朱温建**梁** → 李存勖建**唐** → 石敬瑭建**晋**（向契丹称"儿皇帝"，割燕云十六州）→ 刘知远建**汉** → 郭威建**周** → 赵匡胤陈桥兵变、受周禅建宋。
- "皆有由"：每个朝代兴起都有缘由——篡位、借兵、兵变，没有一个是"正常接班"。
- 记忆钩子：**梁唐晋汉周——五个姓，五套篡夺故事**。
