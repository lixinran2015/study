# 四书

> 一句白话：儒家的核心教材包——《论语》（孔子语录）、《孟子》（仁义雄辩）、《中庸》（子思，不偏不易）、《大学》（曾子，修齐治平），外加《孝经》作预科：先孝经、再四书、后六经，顺序不能乱。

## 它解决什么问题

儒家学习路径"读什么、按什么顺序读"：小学（文字学）打底 → 四书立本 → 六经拓展。四书是历代科举的核心课本。

## 我的解释 / 例子

- **论语**二十篇：孔子弟子及再传弟子辑录的孔子言行，"群弟子，记善言"。
- **孟子**七篇：孟轲与弟子万章、公孙丑等所著，雄辩地讲道德、说仁义。
- **中庸**：子思（孔伋，孔子之孙）所作——"中"不偏不倚，"庸"恒常不易。
- **大学**：传为曾子（曾参）所述——格物、致知、诚意、正心、修身、齐家、治国、平天下"八目"；三字经节取"自修齐，至平治"。
- 记忆钩子：**论孟中大学 + 孝经预科**；作者链 = 弟子（辑）→ 轲（著）→ 孙（思）→ 参（述）。
