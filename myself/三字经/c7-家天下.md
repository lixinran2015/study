# 家天下

> 一句白话：禹把王位传给自己的儿子启，"公天下"从此变成"家天下"——夏四百载、商六百载、周八百载，三个数字就是上半部中国史的骨架。

## 它解决什么问题

朝代为什么更替？"家天下"埋下伏笔：天下是一家一姓的私产，坐久了就会亡。三个年数则是背历史的第一批钉子。

## 我的解释 / 例子

- **家天下**：尧舜禹禅让是"公天下"；禹传子启，世袭制开始，"家天下"登场。"迁夏社" = 社稷迁走 = 亡国。
- **三个年数**（约数）：夏约四百载（约前2070–前1600）、商约六百载（约前1600–前1046）、周约八百载（前1046–前256，含东周）——周最长久，所以三字经说"八百载，最长久"。
- 链条：夏传子 → 汤伐夏 → 武王诛纣——每次更替都因为上一个"家"失了德。
- 记忆钩子：**四、六、八**——三个递增的偶数，就是三个朝代的长度。
