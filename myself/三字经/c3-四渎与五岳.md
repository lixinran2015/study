# 四渎与五岳

> 一句白话：四条独流入海的大河（江、河、淮、济）是"水的主干"，五座名山（泰、华、嵩、恒、衡）是"山的代表"——古人用九个专名为山水定了坐标。

## 它解决什么问题

没有地图的时代，如何定位"名山大川"？答案是约定俗成的清单：四渎定水系，五岳定山系，一提名字全国人民都知道是哪。

## 我的解释 / 例子

- **四渎**：长江（江）、黄河（河）、淮河（淮）、济水（济）。渎 = 独流入海的大河。济水河道今已湮没，故今多称"江河淮济"为古四渎。
- **五岳**：东岳泰山（岱）、西岳华山、中岳嵩山、北岳恒山、南岳衡山。
- 易混点：**恒 ≠ 衡**——恒山在北（山西大同），衡山在南（湖南衡阳），同音异山，写错即错。
- 与千字文联动：千字文"岳宗泰岱，禅主云亭"（chunk5）说同一组山。
- 记忆钩子：**水四条、山五座；渎 = 大水，岳 = 名山**。
