## 调试三板斧

写代码不出错是不可能的，关键是怎么快速找到问题。下面这三招，是我们日常调试最实用的技巧。

### 第一板斧：直接粘贴报错信息

程序报错时，最忌讳的就是自己瞎猜。直接把报错信息丢给 AI，往往一分钟就能定位问题。

**浏览器报错怎么看：**

1. 在网页上按 `F12`（Mac 是 `Fn + F12`），打开开发者工具
2. 点击顶部的 `Console`（控制台）标签
3. 如果看到红色的错误文字，那就是报错信息
4. 选中报错文字，复制粘贴给 Claude Code

**终端报错怎么看：**

1. 运行命令后，如果看到红色的文字或 `Error:` 开头的信息，就是报错
2. 把报错内容完整复制下来（包括前面的文件路径和行号）

**Prompt 示例：**

```
我运行代码时出现了以下报错，请帮我分析原因：
```
[报错内容]
```
```

💡 小提示：复制报错时尽量完整，哪怕你觉得某些内容不重要。AI 能从文件名和行号里找到很多线索。

---

### 第二板斧：让 AI 解释日志/输出

有时候程序没有报错，但结果不对。这时候可以把运行结果和预期结果一起告诉 AI。

**Prompt 示例：**

```
这段代码运行后输出了 XXX，但我预期是 YYY，请帮我看看哪里出了问题。
```

比如：

```
这段代码运行后，列表显示的是 ["苹果", "香蕉"]，但我预期应该是 ["苹果", "香蕉", "橙子"]。请帮我看看哪里漏了。
```

💡 小提示："实际结果 + 预期结果" 这个组合，是最高效的调试 Prompt 之一。

---

### 第三板斧：Working Backwards（从预期反推）

这是一个更高级的思维技巧：先告诉 AI 你想要什么结果，再问它现在的代码缺了什么。

**Prompt 示例：**

```
我想要点击按钮后，列表里的数字全部加 1。请从预期结果反推，告诉我现在的代码缺了什么。
```

这种方法的好处是：
- 你不用纠结代码细节
- AI 会帮你梳理 "从目标到实现" 的完整路径
- 特别适合你只知道"想要什么"，但不知道"怎么写"的时候

## 重构与优化

代码能跑只是第一步，代码写得清楚、好维护，才是真正的进阶。

### 代码太长时怎么拆分

当一个文件超过 300 行，阅读和维护都会变困难。这时候可以请 AI 帮你拆分。

**Prompt 示例：**

```
这个 HTML 文件已经超过 400 行了，请帮我把它拆成一个主 HTML 和一个单独的 JavaScript 文件。
```

### 让 AI 起更好的变量名

好的名字能让代码可读性提升一倍。如果你之前随便起了一些名字，现在可以请 AI 帮你优化。

**Prompt 示例：**

```
请帮我检查一下这段代码里的变量名和函数名，给它们起更清晰、更符合中文习惯的名字。
```

### 请求代码简化

有时候代码能跑，但写法很啰嗦。可以请 AI 在不改功能的前提下优化写法。

**Prompt 示例：**

```
这段代码能更简洁吗？请保留原有功能，只优化写法。
```

## 更高效的 Prompt 技巧

和 AI 协作的效率，很大程度上取决于你怎么提问。下面三个技巧，能让你的 Prompt 质量提升一个档次。

### 给 AI 提供上下文

AI 不知道你的项目用了什么技术栈，所以你要主动说明。

**Prompt 示例：**

```
这是一个 Vue 3 的单文件 HTML 项目，没有使用构建工具。请基于这个前提帮我修改以下代码：
```

### 要求先给思路再写代码

复杂功能不要一上来就要代码，先让 AI 给思路，你确认后再写，能少走很多弯路。

**Prompt 示例：**

```
我想实现 XXX 功能。请先告诉我大致的实现思路，确认没问题后再写代码。
```

### 用 "请解释为什么这样改" 来学习

AI 改完代码后，不要只看结果，要让它解释每一处的用意。这是最高效的学习方式。

**Prompt 示例：**

```
谢谢你帮我改了代码。请解释一下你修改的每一处分别解决了什么问题，我想学习一下。
```

## 多文件项目管理

当你的项目不再是一个简单的 HTML 文件时，就需要考虑怎么组织文件了。

### 什么时候该拆分文件

- 一个 HTML 文件超过 300 行
- 同一个文件里既有界面又有复杂逻辑
- 有一段代码需要在多个地方复用
- 你想让项目结构看起来更专业

### 让 Claude Code 帮你整理目录结构

**Prompt 示例：**

```
请帮我把这个项目整理成更清晰的目录结构。index.html 放根目录，CSS 放 styles/，JavaScript 放 scripts/，并更新所有引用路径。
```

### 批量修改多个文件

Claude Code 可以直接操作你项目里的多个文件。比如统一修改所有 HTML 的标题：

**Prompt 示例：**

```
请帮我把项目里所有 HTML 文件中的标题统一改成"我的应用"。
```

💡 小提示：Claude Code 能看到你当前目录下的所有文件，所以批量修改是它的强项。大胆用！

## Skills 速查

Claude Code 除了聊天对话，还有很多**内置的 Skills（专业技能命令）**。你可以把它们理解为 "快捷功能键"，能帮你更高效地完成特定任务。

### 什么是 Skills

Skills 是 Claude Code 的扩展能力，每个 Skill 都针对一类任务做了专门优化。比如自动提交代码、审查 Pull Request、生成测试等等。

### 常见 Skills 举例

| Skill | 作用 |
|-------|------|
| `/commit` | 自动整理改动并提交代码 |
| `/review-pr` | 审查 GitHub 上的 Pull Request |
| `/test` | 为代码生成测试用例 |
| `/refactor` | 重构代码，优化结构 |

### 如何查看可用 Skills

在你的项目目录下，运行以下命令：

```bash
claude skills
```

或者在 Claude Code 的对话框里输入：

```
/help
```

**Prompt 示例：**

```
请帮我列出当前可用的 Skills，并告诉我哪些适合初学者使用。
```

💡 小提示：Skills 会不断更新，建议你每隔一段时间就用 `claude skills` 看看有没有新功能。

## 下一步学习建议

学完这个教程，你已经迈出了编程学习的第一步。接下来怎么走？这里有两条常见的学习路径供你参考。

### 前端学习路径

```
HTML / CSS 基础 → JavaScript 基础 → Vue / React 框架 → 全栈开发
```

如果你喜欢做网页、做 App 界面，前端是很好的方向。建议先巩固 JavaScript，再选一个框架（Vue 对中文用户更友好）深入学习。

### Python 学习路径

```
Python 基础语法 → 爬虫 / 自动化脚本 → 数据分析 / Web 后端
```

如果你想写脚本处理文件、爬取数据、或者做数据分析，Python 是最适合初学者的语言。

### 持续练手建议

- **每天用 Claude Code 做一件小事**：整理文件、查数据、改网页，哪怕只有 10 分钟
- **遇到重复操作就问"能不能用脚本自动化？"**：这是程序员思维的起点
- **不要怕报错**：把报错当作学习材料，贴给 AI，搞懂原因，你就又进步了一点
