# Claude Code 初学者教程

> 面向完全编程新手的分章节学习小册子。你不需要任何编程基础，只需要一台电脑和好奇心。

---

## 这是一本什么样的教程？

这是一本**手把手教你和 AI 一起写代码**的入门教程。全程不需要死记硬背语法，也不需要配置复杂的开发环境。你只需要学会一件事：**怎么把需求清楚地告诉 Claude Code，然后一步步验证结果**。

通过 5 个章节 + 3 个实战项目，你将从完全零基础，成长为能独立做出一个小网页、一个实用脚本、一个完整记账应用的学习者。

## 适合谁？

- 完全不懂编程，但想尝试用 AI 写代码的新手
- 对传统编程课感到枯燥，想边做边学的人
- 听说过 Claude Code，但不知道怎么开口和它对话的人

## 你将学到什么

- 如何安装和配置 Claude Code（含国内模型连接方案）
- 如何通过与 AI 对话来完成编程任务
- 如何描述需求、运行代码、排查错误
- 如何用 Vue 做简单网页，用 Python 写实用脚本

## 项目实战

1. **心情记录卡片** — 一个能记录心情的互动小网页
2. **天气查询脚本** — 用 Python 查天气并保存结果
3. **记账小应用** — 带统计和分类的完整记账工具
