## 脚本 vs 网页

在前面的章节里，我们做的都是“网页”——有按钮、有输入框、有颜色，打开浏览器就能看到。

而**脚本（Script）**没有这些华丽的界面，它直接在**终端（命令行）**里运行。你输入命令，程序执行，输出结果，任务完成。

脚本非常适合做自动化任务、数据获取、文件处理等“幕后工作”。很多程序员每天的工作，其实大部分时间都在和各种脚本打交道。

---

## 什么是 API

**API**（Application Programming Interface，应用程序编程接口）可以理解为程序和外部世界交换数据的“桥梁”。

用一个通俗的比喻：

> API 就像**餐厅的菜单和后厨**。你坐在桌前，看着菜单点菜（发送请求），服务员把单子递给后厨，后厨做好菜再端上来（返回数据）。你不需要知道菜是怎么炒的，只要会点菜，就能吃到饭。

在我们的天气脚本里，我们会向“和风天气”的服务器“点菜”——发送城市名，服务器把天气数据“端上来”。

---

## 申请和风天气 API Key

要使用和风天气的数据服务，首先需要注册一个免费账号，获取专属的 API Key（相当于你的“用餐卡”）。

**步骤：**

1. 打开浏览器，访问 [qweather.com](https://www.qweather.com/)
2. 点击右上角注册账号
3. 登录后进入“控制台”或“开发设置”
4. 创建一个“免费版”项目
5. 复制生成的 **API Key**
6. 把 Key 粘贴到代码最上方的 `API_KEY = "你的_API_KEY"` 中

> **提示**：和风天气的免费 Key 在创建后可能需要等待几分钟才能生效，如果一开始提示 Key 无效，请稍等片刻再试。

## 分步实现指引

### Step 1：新建文件

在 `tutorial/examples/` 目录下新建一个文件，命名为 `03-weather.py`。

### Step 2：粘贴代码并替换 API Key

把本章提供的示例代码复制进去，把文件顶部的 `API_KEY = "你的_API_KEY"` 替换成你申请到的真实 Key。

### Step 3：运行脚本

打开终端，进入文件所在目录，运行：

- **macOS / Linux**：
  ```bash
  python3 03-weather.py
  ```
- **Windows**：
  ```bash
  py 03-weather.py
  ```

### Step 4：输入城市名，查看结果

程序会提示你输入城市名，比如输入 `北京` 或 `上海`。稍等片刻，终端会打印出天气信息，同时在同一目录下生成一个 `城市名-YYYY-MM-DD.txt` 的文件。

## 常见报错排查

| 报错信息 | 可能原因 | 解决办法 |
|---------|---------|---------|
| `ModuleNotFoundError: No module named 'requests'` | 代码里用了 `requests` 库，但你的电脑没安装 | 我们的示例使用 Python 内置的 `urllib`，不会出现这个问题 |
| 网络连接超时 / `URLError` | 网络不通，或需要代理 | 检查网络连接，或尝试切换网络环境 |
| 城市不存在 | 输入了错别字，或城市名过于生僻 | 检查输入，尝试用更常见的城市名 |
| API Key 无效 | Key 还没激活，或复制时多了空格 | 确认 Key 已激活，重新复制粘贴 |

## 教学重点小结

- **API** 是程序和外部世界交换数据的桥梁。学会“点菜”，就能获取无穷无尽的数据。
- **脚本**可以直接读写电脑上的文件，不需要浏览器，适合做自动化任务。
- **报错信息**是调试的好帮手。遇到问题时，把完整的报错信息复制给 Claude Code，它能更快帮你定位原因。

## 本章挑战

**任务**：把脚本升级成查询**未来 3 天天气预报**，并写入同一个文本文件。

**需要显示的信息**：

- 日期
- 最高温 / 最低温
- 白天天气
- 夜间天气
- 风向风力

**提示**：

- 和风天气的 3 日预报 API 地址是：
  ```
  https://devapi.qweather.com/v7/weather/3d?location={城市编码}&key={API_KEY}
  ```

- 返回的数据里，天气预报在 `daily` 数组中，每一天都是一个对象。

**参考 Prompt**：

```
请帮我把这个脚本改成查询未来 3 天天气预报，每天显示日期、最高温、最低温、白天天气、夜间天气，然后写入同一个文件。
```
