# 第 1 章：第一次对话 — 心情记录卡片

欢迎来到 Claude Code 初学者教程的第一章！在这一章里，我们不会讲太多理论知识，而是直接动手做一个小项目，让你体验一次完整的"描述需求 → AI 写代码 → 自己运行 → 看到效果"的循环。

---

## 学习目标

完成第一次"描述需求 → AI 写代码 → 自己运行 → 看到效果"的完整循环。

---

## 项目效果预览

完成后的网页是这样的：

- 页面顶部有四个心情选项，每个心情都有一个可爱的 emoji 表情：开心 😊、平静 😌、难过 😢、兴奋 🤩。
- 你可以点击选择当前的心情。
- 下面有一个输入框，可以写一句话描述此刻的感受。
- 点击"生成卡片"按钮后，页面下方会出现一张小卡片，卡片上显示着你选中的表情、你写的描述文字，以及卡片的生成时间。
- 生成的卡片会按照时间顺序依次排列在页面下方。

---

## 跟 Claude Code 说 — Prompt 示例

你可以直接把下面这段话复制发给 Claude Code：

```
请帮我写一个单文件的 HTML 网页，使用 Vue 3 CDN。网页功能是：用户可以选择心情表情（开心😊、平静😌、难过😢、兴奋🤩），输入一句话描述，点击"生成卡片"按钮后，在页面下方显示一张包含心情表情、描述文字和生成时间的小卡片。卡片按时间顺序排列。请把样式做得简洁美观一些。
```

> **小提示**：不用担心说得不专业，把你想实现的效果用大白话告诉 Claude Code 就好。越具体，它写出来的代码就越接近你的期望。

---

## 操作步骤

### Step 1：新建文件

在你的电脑上新建一个文件，命名为 `mood-card.html`。

### Step 2：粘贴代码并保存

把 Claude Code 回复给你的代码完整复制，粘贴到 `mood-card.html` 中，然后保存文件。

> 如果你还没有向 Claude Code 提问，现在就把上面的 Prompt 发给它吧！

### Step 3：用浏览器打开

找到你保存的 `mood-card.html` 文件，双击它，系统会自动用浏览器打开。你应该就能看到一个漂亮的心情记录页面了。

### Step 4：试用功能

试着点击不同的心情、输入几句话，然后点击"生成卡片"，看看效果吧！

---

## 遇到问题怎么办？

| 问题 | 解决方法 |
|------|---------|
| 网页打开是空白的 | 检查你的网络是否能正常加载 Vue CDN（`https://unpkg.com/vue@3/dist/vue.global.js`）。如果网络较慢，可能需要稍等片刻。 |
| 浏览器报了红色的错误 | 把报错信息复制下来，直接贴给 Claude Code，它会帮你找出原因。 |
| 不知道怎么新建文件 | 可以请 Claude Code 一步步教你，或者先用系统自带的"记事本"（Windows）/"文本编辑"（Mac）来创建。 |

---

## 教学重点小结

- **如何开口描述需求**：不需要专业术语，用大白话告诉 Claude Code 你想做什么。
- **如何保存和运行代码**：把代码保存成 `.html` 文件，双击就能在浏览器中打开。
- **如何在浏览器中查看效果**：浏览器就是你的"舞台"，每次修改代码后刷新页面就能看到最新效果。

## 本章挑战

### 任务

让心情卡片的背景色根据所选的心情自动变化：

- 开心 = 暖黄色（`#fef3c7`）
- 平静 = 浅蓝色（`#dbeafe`）
- 难过 = 灰蓝色（`#e2e8f0`）
- 兴奋 = 粉红色（`#fce7f3`）

### 提示

可以在 Vue 的 `data` 里给每种心情配一个颜色，然后在卡片元素上用 `:style` 动态绑定背景色。例如：

```html
<div class="card" :style="{ backgroundColor: card.color }">
```

### 参考 Prompt

如果你想让 Claude Code 直接帮你改，可以发这段话：

```
我想让心情卡片的背景色根据心情变化，比如开心是暖黄色，平静是浅蓝色，难过是灰蓝色，兴奋是粉红色。可以在 Vue 的 data 里给每种心情配一个颜色，然后用 :style 动态绑定到卡片的背景色上吗？
```

挑战版的参考代码已经为你准备好了，可以打开 [`examples/01-mood-card-challenge.html`](./examples/01-mood-card-challenge.html) 查看。
