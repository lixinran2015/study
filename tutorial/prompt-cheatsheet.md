# Claude Code Prompt 速查表

> [← 上一章：附录](./appendix-troubleshooting.md) | [返回目录](./README.md)

这是一份可以直接复制使用的 Prompt 参考。遇到对应场景时，复制粘贴到 Claude Code 的输入框即可。

---

## 需求描述类

### 1. 生成心情卡片网页

```
帮我写一个单文件的 HTML 网页，使用 Vue 3 CDN。网页功能是：用户可以选择心情表情（开心😊、平静😌、难过😢、兴奋🤩），输入一句话描述，点击"生成卡片"按钮后，在页面下方显示一张包含心情表情、描述文字和生成时间的小卡片。卡片按时间顺序排列。请把样式做得简洁美观一些。
```

### 2. 生成天气查询 Python 脚本

```
请帮我写一个 Python 脚本，实现以下功能：
1. 在终端询问用户要查询的城市名称；
2. 调用和风天气的 Geo API 查询城市编码；
3. 调用实时天气 API 获取该城市的当前天气；
4. 在终端打印天气信息（温度、天气状况、风向、湿度）；
5. 把结果保存到以"城市名-YYYY-MM-DD.txt"命名的文件中；
6. 使用 Python 标准库的 urllib，不需要额外安装第三方库；
7. 加上基本的错误处理（网络错误、城市不存在等）。
请用中文写注释和输出信息。
```

### 3. 生成记账应用网页

```
请帮我写一个单文件 HTML 网页，使用 Vue 3 CDN，做一个记账应用。顶部显示总收入、总支出、结余三个统计数字；中间是一个表单，可以添加收入或支出记录（包含类型、分类、金额、备注、日期）；下面是记录列表，支持删除。收入用绿色显示，支出用红色显示。数据用 localStorage 保存，刷新不丢失。
```

## 代码解释类

### 4. 解释 HTML 文件结构

```
请逐段解释这个 HTML 文件里的代码是什么意思。我不太懂 Vue，请用简单的话告诉我 <template>、<script>、<style> 分别做了什么。
```

### 5. 解释模板语法与响应式原理

```
这段代码里的 `{{ variable }}` 是什么作用？为什么它可以自动更新？
```

### 6. 解释 API 的概念

```
请用大白话解释一下什么是 API，为什么程序需要调用 API？
```

---

## 修改优化类

### 7. 添加卡片悬停效果

```
我想让卡片在鼠标放上去的时候微微向上浮起，并加深阴影，请帮我改 CSS。
```

### 8. 添加删除卡片功能

```
给每张卡片右上角加一个删除按钮，点击后弹出确认提示，确认后再删除这张卡片。
```

### 9. 优化代码写法

```
这段代码能更简洁吗？请保留原有功能，只优化写法。
```

### 10. 改进命名

```
请帮我检查一下这段代码里的变量名和函数名，给它们起更清晰、更符合中文阅读习惯的名字。
```

## 调试排查类

### 11. 分析报错信息

```
我运行代码时出现了以下报错，请帮我分析原因：
```
[把报错信息粘贴在这里]
```
```

### 12. 排查网页空白问题

```
网页打开是空白的，请帮我检查这段代码哪里有问题。我已经把代码和浏览器 Console 里的报错信息一起贴上了。
```

### 13. 排查输出不符合预期

```
这段代码运行后输出了 XXX，但我预期是 YYY，请帮我看看哪里出了问题。
```

## 审校学习类

### 14. 请求代码优化建议

```
这段代码已经能跑了，请帮我检查一下结构和逻辑，给我优化建议。
```

### 15. 学习修改思路

```
请解释你为什么要这样修改，我想学习一下这里的思路。
```

### 16. 询问功能扩展思路

```
如果我要继续加一个"按月筛选"功能，应该从哪里入手？请给我实现思路。
```

---

## 项目管理类

### 17. 整理项目目录结构

```
请帮我把这个项目整理成更清晰的目录结构。index.html 放根目录，CSS 放 styles/，JavaScript 放 scripts/，并更新所有引用路径。
```

### 18. 批量修改 HTML 标题

```
请帮我把项目里所有 HTML 文件中的标题统一改成"我的记账应用"。
```

---

💡 小提示：Prompt 不是咒语，关键是把事情说清楚。描述越具体，AI 的回复就越准确。
